## // AI / ML — built, not just listed

**DocuMind — AI Document Intelligence Platform** ([repo](https://github.com/chethan747/documind))
Ask questions over your own documents and get answers with citations. A from-scratch RAG engine in pure Python:
- Sentence-aware overlapping chunker, TF-IDF vectoriser built from scratch
- BM25 ranking alongside TF-IDF, with a combined mode and cosine similarity
- Extractive QA with `[source]` citations, SQLite document store, ingestion pipeline (dedup by content hash)
- Persistent, versioned index save/load with document metadata
- Next: answer reranking, an evaluation harness with hit-rate metrics, REST API + web UI, Docker/CI, v1.0

**Neural net from scratch** ([daily-projects](https://github.com/chethan747/daily-projects))
Pure-Python neural network, no ML frameworks — verified working: XOR 4/4, blobs 99%.

**ML toolkit in practice:** Python · TF-IDF / BM25 · ranking & retrieval · cosine similarity · chunking · evaluation metrics · SQLite
